CAPA RACIM Matrix

General Contractor setup only • No subcontractors
R = Responsible • A = Accountable • C = Consulted • I = Informed • M = Monitoring
R ResponsiblePerforms the work or prepares the required CAPA output.
A AccountableOwns final correctness, approval, and closure of the activity.
C ConsultedProvides technical input before the activity is finalized.
I InformedReceives updates or records after decisions/actions are made.
M MonitoringTracks progress, verifies follow-up, and escalates delays or repeat issues.
Notes:
  • QAQC is accountable for NCR/CAPA documentation quality, root cause adequacy, verification, evidence review, and final quality closure.
  • PM is accountable for execution resources, schedule impact, and site implementation when the action affects construction delivery.
  • OM is accountable for management review, trend analysis, and organizational process improvement.
  • Project Engineers are responsible by discipline. Use the PE column that matches the affected work package.
  • When subcontractor is available, the subcontractor may become responsible for implementation, but the General Contractor remains accountable through QAQC, PM, and OM.
  • If the Project Superintendent is not available, the PM assumes responsibility for superintendent-led CAPA scopes while QAQC retains quality accountability.
